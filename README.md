Sales Analysis Project 



Overview:



This project analyzes sales data using Python and Pandas to understand product performance and category sales.



Objectives:


1.Identify top-performing .



2.Compare sales across product categories.


3.Analyze quantities sold.


4.Extract useful business insights from the data.


Tools Used

1.Python


2.Pandas


3.Matplotlib


4.Jupyter Notebook


## Key Findings

-Phone generated the highest total sales.

-Laptop had the highest average sales value per unit.

-Mobile was the highest-performing product category by sales.

-Accessories recorded the highest quantity sold by category
